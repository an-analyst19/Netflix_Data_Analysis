# Netflix Data Analysis

## Project Overview
An Exploratory Data Analysis (EDA) project on Netflix Movies and TV Shows using Python.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Netflix Movies and TV Shows dataset containing information about titles, directors, cast, countries, release years, ratings, and genres.

## Analysis
- Data cleaning and preprocessing
- Handling missing values
- Movies vs TV Shows distribution
- Content ratings analysis
- Country-wise content distribution
- Exploratory data visualizations

## Objective
To explore Netflix's content catalog and identify interesting patterns and trends through data analysis.
